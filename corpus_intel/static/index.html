      Slicer

      Carve the corpus into named subsets. Build them with a boolean query, draw a random or stratified sample, split the corpus into equal chunks for parallel coding, or combine two existing slices with set operations.

      Build a corpus first

      The slicer runs boolean queries against the merged corpus text column. Head to Corpus, pick your datasets and click Build corpus — then come back here.

      Boolean query i

      Syntax guide
      • AND / OR / NOT — operators are case-insensitive
      • "exact phrase" — match a literal phrase
      • climat* — wildcard: matches climate, climatic, climatology…
      • (A OR B) AND C — parentheses for grouping
      • Adjacent words without an operator are treated as implicit AND

      Column-targeted terms — field:value:

      • author: / handle: / name: — author fields (word match)
      • url: / link: — URL substring
      • hashtag: / tag: — hashtags column
      • lang: / language: — exact code (e.g. lang:de)
      • country: — exact code (e.g. country:DE)
      • platform: — exact (e.g. platform:twitter)
      • source: / dataset: — source_dataset substring
      • id: / post_id: — post_id substring
      • Quote values with spaces: author:"Greta Thunberg"

      Examples: climate AND (change OR warming) NOT satire · lang:de AND climate* · author:realdonald AND url:youtube.com

      Codebook & Coding

      Define your own categories, tag rows one-by-one with keyboard shortcuts, and check how reliably two people agree when they code the same rows.

      Sign in as a coder

      Every tag is stamped with the coder who placed it — so before you can code, you need to set your name in Settings. This is what makes inter-coder agreement possible.

      Start with a codebook

      A codebook is the set of categories you will tag rows with (e.g. hate speech, harassment, misinformation, legitimate). Use the starter preset to get moving, or create your own from scratch.

      Topics

      Discover the main themes in your corpus. Step 1 — Claude reads a sample and proposes named topics. Step 2 — every remaining row is classified into one of them (or into an "Other" bucket for anything that doesn't fit). You can rename or merge topics at any point.

      Analytics

      Descriptives, volume over time, cross-tabs and top terms — scoped to the whole corpus or a saved slice. Toggle Compare to pit two slices against each other.

      Build a corpus on the Corpus tab first, then come back here.

      Scope

      Pick a slice (or keep the whole corpus). Turn on compare to analyse two slices side-by-side.

      Descriptives

      Row counts, date coverage, unique authors, engagement means, top facets and top authors (both by post count and by summed engagement).

      Volume over time

      Rows (or an engagement metric) bucketed by time. Group by a categorical column to see a stacked breakdown.

      Sums count every row's value per bucket; averages divide by the number of rows in that bucket.

      Cross-tab

      Count (or share) of rows at every combination of two categorical columns.

      Row % shows how each row is distributed across columns. Column % shows how each column is built up from rows. Total % shows each cell's share of the whole.

      Top terms i

      Most frequent words or phrases in the text column. Pick the stopword language that matches your corpus (German, French, etc.) so common words don't dominate the chart.

      Anthropic API key

      Paste an Anthropic key to unlock AI features: column-mapping suggestions today, and classification, topic discovery and report writing in later updates. The key stays in memory for this session only — it is never written to disk.

      No Anthropic key on file.

      AI features (column mapping, codebook suggestions, classification, topic induction, report writing) are disabled until you paste a key. Get one at console.anthropic.com.

      To fully revoke a key, also disable it at console.anthropic.com/settings/keys. "Forget" here only removes it from this session's memory.
